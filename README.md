# Y&C Landscaping & Masonry

Marketing website for **Y&C Landscaping & Masonry** — hardscape design, retaining walls, patios, walkways, stone walls, fence installation, and year-round property care.

Saugus, MA · serving the North Shore of Massachusetts.

## Stack

Single self-contained `index.html` — no build, no dependencies, no server required.
Fonts pulled from Google Fonts (Fraunces + Manrope). Everything else inlined.

## Run locally

Double-click `index.html`, or serve it:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Edit

Open `index.html` in any editor. Brand colors, services, projects, and copy live in the file (CSS custom properties at the top, JS data objects at the bottom of the `<script>` block).
